Tuned Analog PID Controller

Designed and simulated an analog PID controller for a 3rd-order plant; achieved ~59% faster time-to-peak and ~2% overshoot while matching MATLAB and LTSpice results.

Project Overview

This project implements a tuned analog PID controller for a third-order plant with poles at 70, 90, and 100 rad/s. I modeled the plant in MATLAB, verified frequency and time-domain behavior, and then implemented the equivalent circuit in LTSpice. I designed the controller using classical techniques (frequency response + root locus) and validated tuning approaches including Ziegler–Nichols variants and a custom tuning strategy. The final tuned controller achieved a ~58.9% reduction in time-to-peak, ~39.7% reduction in settling time, and ~2% overshoot, with strong agreement between MATLAB and LTSpice.

Tools: MATLAB (Control System Toolbox), LTSpice

Domain: Classical control, analog circuit simulation

Focus: PID tuning, model validation, transient performance

Plant Modeling + Validation

Before designing the controller, the system plant was implemented and verified to ensure the physical circuit accurately represented the intended transfer function. The plant was modeled as a third-order system composed of three cascaded RC stages, each representing a single pole in the system dynamics. Component values were selected to map the desired pole locations to practical resistor and capacitor values, allowing the theoretical model to be directly implemented in LTSpice. Frequency-domain analysis was then used to validate the behavior of the implemented plant. The resulting Bode plot confirmed the expected third-order characteristics, including the progressive magnitude roll-off and phase lag associated with three poles. Agreement between the analytical model and simulation ensured the plant behaved as expected prior to beginning PID controller design and tuning.

  • Compared simulated magnitude response with theoretical values at key frequencies
  • Verified −60 dB/decade roll-off consistent with a third-order system
  • Validated plant behavior prior to controller design

Controller Design Approach

After validating the plant model, the controller was designed using a pole-placement approach guided by root locus analysis. The goal was to move the dominant closed-loop poles to locations that improved transient response while maintaining the specified overshoot constraint. Root locus visualization allowed the effect of gain changes on system stability and damping ratio to be evaluated before implementing the controller.

Controller performance was then validated through time-domain step response simulations. As integral and derivative terms were introduced, the design was iteratively refined to balance rise time improvement, overshoot limits, and overall stability. This workflow ensured the final PID controller was derived from analytical design principles rather than purely empirical tuning.

Design Targets

  • Time-to-peak improvement ≥ 50%
  • Overshoot ≤ 9.48%
  • Stable closed-loop response with well-damped dominant poles

Methods Used

  • Root locus analysis for gain selection and dominant pole placement
  • Damping ratio targeting to satisfy overshoot requirements
  • Time-domain validation using step response simulation
  • Tuning comparison (Ziegler–Nichols variants, Skogestad IMC tuning, and custom tuning)

Analog PID Implementation

After determining suitable controller gains through root locus analysis and step-response validation, the PID controller was implemented as an analog circuit in LTSpice. The proportional, integral, and derivative terms were realized using op-amp based gain, integrator, and differentiator stages. Controller gains were translated into resistor and capacitor values so that the physical circuit directly represented the designed transfer function.

The PID controller, summing junction, and plant were then integrated into a full closed-loop simulation. This allowed the controller behavior to be verified under realistic circuit conditions and compared against the expected MATLAB response. Agreement between analytical predictions and circuit-level simulation confirmed the implementation accurately reproduced the designed controller dynamics.

Results

The final PID controller achieved the desired transient performance while maintaining stable closed-loop behavior. Simulation results from MATLAB were compared against the LTSpice circuit implementation to verify that the analytical design translated accurately to the analog realization. The close agreement between both environments confirms that the controller design, component mapping, and circuit implementation behaved as expected.

Performance Summary

  • Time to peak: 24.3 ms (MATLAB) vs 24.36 ms (LTSpice)
  • Settling time: 54.5 ms (MATLAB) vs 54.47 ms (LTSpice)
  • Percent overshoot: 2.0% (MATLAB) vs 2.1% (LTSpice)
  • Targets met: ≥50% improvement in time-to-peak and ≤9.48% overshoot

Key Takeaways

  • Cross-tool validation: MATLAB system modeling matched LTSpice circuit simulation
  • Demonstrated a structured controls workflow (model → design → validate)
  • Successfully translated theoretical PID gains into a realizable analog circuit
  • Verified transient performance improvements while maintaining stability
