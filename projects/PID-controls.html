Tuned Analog PID Controller

Designed and simulated an analog PID controller for a 3rd-order plant; achieved ~59% faster time-to-peak and ~2% overshoot while matching MATLAB and LTSpice results.

Project Overview

This project implements a tuned analog PID controller for a third-order plant with poles at 70, 90, and 100 rad/s. I modeled the plant in MATLAB, verified frequency and time-domain behavior, and then implemented the equivalent circuit in LTSpice. I designed the controller using classical techniques (frequency response + root locus) and validated tuning approaches including Ziegler–Nichols variants and a custom tuning strategy. The final tuned controller achieved a ~58.9% reduction in time-to-peak, ~39.7% reduction in settling time, and ~2% overshoot, with strong agreement between MATLAB and LTSpice.

Tools: MATLAB (Control System Toolbox), LTSpice

Domain: Classical control, analog circuit simulation

Focus: PID tuning, model validation, transient performance

Controller Design Approach

I used root locus to select closed-loop pole placement consistent with the overshoot constraint and transient goals. The gain selection was validated by step response simulation, and the design approach was iterated as integral/derivative action was introduced. This workflow ensured the controller design was driven by pole placement and verified against time-domain specs, not trial-and-error.

Design Targets

  • Time-to-peak improvement ≥ 50%
  • Overshoot ≤ 9.48%

Methods Used

  • Root locus + damping ratio targeting
  • Time-domain validation with step response
  • Tuning comparison (Z-N variants + custom tuning + Skogestad)
