Tuned Analog PID Controller

Designed and simulated an analog PID controller for a 3rd-order plant; achieved ~59% faster time-to-peak and ~2% overshoot while matching MATLAB and LTSpice results.

Project Overview

Designed and implemented an analog PID controller for a third-order system (poles at 70, 90, 100 rad/s), with validation across MATLAB and LTSpice.

  • Design: Root locus + frequency-domain methods
  • Implementation: Op-amp based analog PID circuit
  • Validation: Cross-verified simulation and circuit behavior
  • Result: ~59% reduction in time-to-peak, ~40% reduction in settling time, ~2% overshoot

Tools: MATLAB (Control System Toolbox), LTSpice

Domain: Classical control, analog circuit simulation

Focus: PID tuning, model validation, transient performance

Plant Modeling + Validation

Modeled the plant as a third-order system using cascaded RC stages, mapping pole locations directly to component values for circuit implementation.

Implementation

  • Mapped poles using \( C = \frac{1}{R\omega_p} \)
  • Built modular RC stages representing system dynamics
  • Enabled direct translation from model → circuit

Validation

  • Verified −60 dB/decade roll-off via Bode analysis
  • Matched simulated response to theoretical model
  • Confirmed plant behavior prior to controller design

Plant Implementation

  • Mapped desired pole frequencies to RC component values using C = 1/(Rωp)
  • Implemented the plant as three cascaded RC stages representing system poles
  • Structured stages modularly to simplify verification and debugging

Frequency-Domain Verification

  • Compared simulated magnitude response with theoretical values at key frequencies
  • Verified −60 dB/decade roll-off consistent with a third-order system
  • Validated plant behavior prior to controller design

Controller Design Approach

Designed the controller using root locus to place dominant poles for improved transient response while maintaining overshoot constraints.

Design Goals

  • ≥50% improvement in time-to-peak
  • Overshoot ≤ 9.48%
  • Stable, well-damped closed-loop response

Methods

  • Root locus for gain selection and pole placement
  • Damping ratio targeting for overshoot control
  • Step response validation in time domain
  • Tuning comparison: Ziegler–Nichols, IMC, custom

Analog PID Implementation

Implemented the PID controller as an analog circuit using op-amp based proportional, integral, and derivative stages.

  • Realization: Converted gains to resistor/capacitor values
  • Integration: Combined controller + plant into closed-loop system
  • Validation: Matched LTSpice response to MATLAB predictions

Circuit Implementation

Baseline Step Response

  • Measured key transient metrics (Tp, Ts, and percent overshoot)
  • Established baseline performance for comparison with tuned responses
  • Guided tuning tradeoffs between response speed and overshoot

Results

Final controller met all performance targets with strong agreement between MATLAB and LTSpice, validating both the design methodology and circuit implementation.

Performance

  • Tp: 24.3 ms (MATLAB) vs 24.36 ms (LTSpice)
  • Ts: 54.5 ms vs 54.47 ms
  • %OS: 2.0% vs 2.1%

Key Takeaways

  • Accurate model → circuit translation
  • Consistent behavior across simulation environments
  • Structured workflow: model → design → validate
  • Successful analog realization of PID control
